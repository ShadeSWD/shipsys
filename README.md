# shipsys — Судовые устройства и системы: живые расчёты

Статический сайт по курсам СПбГМТУ «Судовые устройства» и «Судовые системы»:
два сквозных инженерных расчёта с живым пересчётом в браузере (ванильный
JS, схемы SVG, без сборки).

**Прод:** https://shadeswd.duckdns.org/shipsys/

## Содержание
- `site/` — сам сайт (чистые HTML/CSS/JS, без сборки)
  - `index.html` — обзор и «зачем это всё»
  - `rudder.html` — проектирование пера руля морского сухогруза по Правилам
    РМРС: площадь и балансировка, профиль NACA0020, проверка эффективности,
    силы F₁/F₂ и моменты, диаметр баллера, толщина обшивки — со схемой кормы
    и живым пересчётом от L, B, d, C_b, v
  - `hydraulics.html` — гидравлика судовых систем: цистерна с избыточным
    давлением, трубопровод из двух участков с коленами; уравнение Бернулли с
    потерями, подбор диаметра сеткой и итерации до сходимости 5 %
  - `sources.html` — источники (пояснительные записки курсовых СПбГМТУ,
    Правила РМРС ч. III, РД 5.76.038-84, учебники)
  - `assets/` — `style.css`, общий `site.js`, а также движки страниц
    `rudder.js` / `rudder-extra.js` / `hydraulics.js`
- `deploy/` — docker-compose (nginx:alpine, `127.0.0.1:8069`) + конфиг nginx
- `tests/` — тесты целостности сайта (pytest)

## Стек
Статика: HTML + CSS + ванильный JS, чертежи рисуются прямо в странице (SVG).
Раздача — nginx в Docker с чистыми URL (`try_files $uri $uri.html $uri/`).

## Запуск локально
```bash
cd deploy && docker compose up -d   # проект называется shipsys (name: обязателен!)
```
Сайт поднимется на `127.0.0.1:8069`. Наружу отдаётся через host-nginx:
`location /shipsys/`.

## Тесты
```bash
pip install pytest --break-system-packages -q
python3 -m pytest tests/ -q
```
Тест-кит параметризуется по файлам: для каждой HTML-страницы проверяет разбор,
отсутствие дублей `id` и целостность локальных ссылок/ассетов (с учётом
clean-URL nginx), для каждого JS — синтаксис через `node --check`.
