Осушительная система: диаметры труб и подбор насоса

Осушительная система удаляет за борт воду, скапливающуюся в трюмах и отсеках при мойке, отпотевании, малых течах и после тушения пожара. Её проектирование — задача с жёстким внешним ограничением: диаметры труб задаются правилами классификационного общества по размерениям судна, а насос подбирается по каталогу так, чтобы обеспечить требуемую подачу и при этом не «сорвать» всасывание — разрежение перед насосом не должно превысить допустимую вакуумметрическую высоту.

1. Диаметры по правилам

Диаметр осушительной магистрали и приёмных отростков определяют по главным размерениям (в миллиметрах):

$$d_{\text{м}} = 1{,}68\sqrt{L\,(B + D)} + 25, \qquad d_{0} = 2{,}15\sqrt{l\,(B + D)} + 25,$$

где \(L, B, D\) — длина, ширина и высота борта судна, м; \(l\) — длина осушаемого отсека по днищу, м. Отросток к клапанной коробке, собирающий несколько приёмников, проверяется по условию

$$d_{\text{м}} \geqslant d_{0} \geqslant \sqrt{d_{01}^{2} + d_{02}^{2} + \dots},$$

то есть суммарная площадь сечения приёмников не должна превышать площадь собирающей трубы. Подача осушительного насоса связана с диаметром магистрали:

$$Q_{\text{н}} \geqslant \dfrac{5{,}65}{10^{3}}\,d_{\text{м}}^{2}, \quad \text{м}^3/\text{ч}.$$

Нормативные ограничения: диаметр магистрали не менее 50 мм, приёмных отростков не менее 60 мм; скорость воды в трубопроводе не выше 2,5 м/с; допустимая вакуумметрическая высота всасывания 5–6 м вод. ст.; напор насоса обычно 20–30 м вод. ст.

2. Потери напора

Для каждого участка потери складываются из потерь по длине и местных:

$$H_{i} = \left(\lambda\,\dfrac{l_i}{d} + \sum\zeta\right)\dfrac{v^{2}}{2g}, \qquad v = \dfrac{4Q}{\pi d^{2}}, \qquad Re = \dfrac{v\,d}{\nu},$$

коэффициент трения для технически гладких труб систем:

$$\lambda = 0{,}0032 + 0{,}221\,Re^{-0{,}237}.$$

Суммарный требуемый напор всасывающей ветви сравнивают с допустимым разрежением: если \(H^{\text{тр}}_{\text{вс}} > H^{\text{доп}}_{\text{вак}}\), диаметры увеличивают на ближайший размер сортамента и расчёт повторяют — это и есть рабочая итерация проектирования системы.
