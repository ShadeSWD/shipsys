Гидравлика судовых систем
цистерна под давлением → трубопровод → за борт: найти d₁, l₂ и Q

Классическая задача курса «Судовые системы»: из закрытой цистерны с избыточным давлением над уровнем жидкость уходит за борт по трубопроводу из двух участков с коленами. Известны давление, уровни и часть размеров; нужно подобрать диаметр первого участка d₁, длину второго l₂ и найти расход Q — с честным учётом потерь, итерациями до сходимости.

Схема системы (не в масштабе): над уровнем в цистерне — избыточное давление Pизб; отвод на высоте z₁ — участок d₁, l₁, колено 16°, расширение до d₂, участок l₂, колено 15° и выход за борт на высоте z₂. Базовая плоскость 0–0 — по днищу.

Теория: Бернулли с потерями

Между свободной поверхностью в цистерне (уровень H, давление Pизб, скорость ≈ 0) и сечением трубопровода записывается уравнение Бернулли с учётом потерь:

$$H + \dfrac{P_{\text{изб}}}{\gamma} = z + \dfrac{P_{\text{атм}}}{\gamma} + \dfrac{v^{2}}{2g} + H_{\text{пот}},\qquad \gamma = \rho\cdot g$$ — откуда скорость идеального истечения (\(H_{\text{пот}} = 0\)): $$v = \sqrt{2g\cdot\left(H - z + \dfrac{P - P_{\text{атм}}}{\gamma}\right)}$$

Потери напора складываются из трения по длине и местных сопротивлений: $$H_{\text{пот}} = \sum \lambda\cdot\dfrac{l}{d}\cdot\dfrac{v^{2}}{2g} + \sum \zeta\cdot\dfrac{v^{2}}{2g}$$ — вход в трубу \(\zeta_{1} = 0{,}5\); колено \(\zeta = \zeta_{90^{\circ}}\cdot\theta/90\) (\(\zeta_{90^{\circ}} = 0{,}6\)); внезапное расширение и сужение — по РД 5.76.038-84.

Режим течения определяет число Рейнольдса \(\mathrm{Re} = v\cdot d/\nu\). При \(\mathrm{Re} \ge 120\cdot(d/\Delta)^{1{,}125}\) течение — в зоне квадратичного сопротивления: шероховатость Δ полностью определяет трение, и \(\lambda = 0{,}25/\lg^{2}(3{,}7\cdot d/\Delta)\) не зависит от скорости. Иначе (переходная область) \(\lambda = 0{,}1\cdot(1{,}46\cdot\Delta/d + 100/\mathrm{Re})^{0{,}25}\).

Ключевая трудность: λ и ζ зависят от скорости, а скорость — от потерь, то есть уравнение неявное. Решают последовательными приближениями: сначала система без потерь, затем подбор d₁ по сетке диаметров, затем итерации скоростей до сходимости. Подробнее про напорное течение и зоны сопротивления — в теории соседнего курса механики жидкости и газа.

Живой расчёт

Исходные данные по умолчанию — вариант курсовой работы. Ограничения задачи: \(l_{1} + l_{2} \le \Sigma L\) и \(d_{1} + d_{2} \le 40\) см, диаметр d₁ подбирается в диапазоне до d₂. Ответ работы: \(d_{1} = 14\) см, \(l_{2} = 95\) см, \(v_{1} = 8{,}8\) м/с, \(v_{2} = 7{,}6\) м/с, \(Q = 0{,}16\) м³/с.

Константы: \(\rho = 1025\) кг/м³, \(P_{\text{атм}} = 0{,}1\) МПа, \(\nu = 1{,}13\cdot 10^{-6}\) м²/с (\(t = 15\) °C), \(g = 9{,}81\) м/с².

Решение по шагам

Сетка подбора d₁ и набор коэффициентов местных сопротивлений воспроизводят расчётную таблицу работы (в том числе форму записи ζ расширения); итоговый расход в работе вычислен через d₂ и v₁ — эта же запись сохранена, рядом даны «строгие» значения по неразрывности.
